# Three-source comparison demo

**Synthetic test documents. Not real claims and not market benchmark evidence.**

This pack uses three repair descriptions from the existing format-1 samples: L/R DOOR, L/SILL PANEL COVER, and Door Fitting Kit. All prices, registrations, claim numbers and policy numbers are invented. The documents have visible demo labels and ordinary selectable PDF text; no hidden extraction markers or preloaded database records are required.

Use a fresh demonstration claim/database. Mixing these files with existing reference invoices will change the P90 values below. Do not reset or delete an existing claim to run this demo.

| Folder | Upload screen | Repair invoice picker | Engineer assessment picker |
|---|---|---|---|
| 01-third-party | Insurer Third Party invoices | All 3 PDFs from `invoices` | All 3 PDFs from `assessments` |
| 02-in-house | EXL/ In house Benchmark invoices | All 3 PDFs from `invoices` | All 3 PDFs from `assessments` |
| 03-new-invoices | Upload new invoice - Compare benchmark | All 3 PDFs from `invoices` | All 3 PDFs from `assessments` |

For each source, upload its six files together, then open **Document intelligence**. Check the three invoice/assessment pairs and approve the mapping. Expand an assessment to see its three parts. The first two sources each have **Benchmark computation**; the third has **Benchmark analysis**.

The three sets have different references and pair only within their own source. The first two sources calculate separate P90s. The new invoices never contribute observations to either reference source.

## Expected comparison

All vehicles are HYUNDAI i30, category Hatchback. Each reference P90 has three observations. Quantities are one and all comparison amounts are net GBP.

| Repair item | Third-party observations | Third-party P90 | In-house observations | In-house P90 | 50/50 price |
|---|---|---:|---|---:|---:|
| L/R DOOR | 100, 110, 120 | 118.00 | 80, 90, 100 | 98.00 | 108.00 |
| L/SILL PANEL COVER | 40, 44, 48 | 47.20 | 32, 36, 40 | 39.20 | 43.20 |
| Door Fitting Kit | 10, 11, 12 | 11.80 | 8, 9, 10 | 9.80 | 10.80 |

Challenge price = (Third-party P90 + In-house P90) / 2, rounded half-up to a penny. Both sources are required. A reduction is actionable only when the billed price exceeds the combined price by **more than 10% and at least GBP 5**. Missing data is never treated as zero. VAT is not included in these line comparisons.

| New invoice | Billed door / sill / kit | Actionable lines | Sum of challenge prices for those lines | Total reduction |
|---|---|---:|---:|---:|
| DEMO-NEW-001 | 150 / 60 / 15 | 2 | 151.20 | 58.80 |
| DEMO-NEW-002 | 160 / 64 / 16 | 3 | 162.00 | 78.00 |
| DEMO-NEW-003 | 170 / 68 / 17 | 3 | 162.00 | 93.00 |

The first invoice's kit has a GBP 4.20 difference, below the GBP 5 minimum, so it is shown but excluded from the challenge and email. The challenge-price total is the sum for challenged lines only, not a revised gross invoice total.

Select **Benchmark analysis**, choose a new invoice, inspect the reference evidence, select the lines and press **Draft email**. Nothing is sent automatically. The three included text drafts were generated by the actual API from this pack and are labelled DO NOT SEND.

## What was verified

| Check | Result |
|---|---|
| Real upload API, no configured AI/OCR service | 18 accepted, zero failures |
| Pairing | Nine pairs, with three extracted parts per assessment |
| Independent source populations | Three invoices and three observations per repair item in each source |
| Source isolation | Uploading in-house and live files did not alter the third-party results; live files did not alter in-house results |
| New invoice calculation and email | All three matched the amounts above |

These are small demonstration populations, not sufficient real-world pricing evidence. Passing this demo does not establish that every client PDF extracts correctly. The original invoice/assessment extraction rules have not been changed in this update.

Rebuild the PDFs from the repository root with `backend/.venv/bin/python scripts/generate_benchmark_comparison_demo.py` (Windows: run the script with the backend's Python environment). The generator requires the backend dependencies.
